# Code of Conduct

SudarshanTechLabs projects follow the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, insults, discriminatory language, or sharing others' private information.
- Assume good faith and help newcomers.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when
representing a project in public.

## Reporting

Report unacceptable behaviour privately to **sudarshantechlabs@gmail.com** with `CONDUCT`
in the subject. Reports are handled confidentially.

## Enforcement

The maintainer may remove, edit, or reject comments, commits, issues, and other
contributions that break this code, and may block contributors who do so repeatedly or
seriously, following the Contributor Covenant enforcement guidelines.
